# Roadmap

## 0.1 — done (this build)
Two anchors, custom slackline solver, placeholder athlete, balance controller,
pump/jump/land/fall, third-person camera, keyboard, HUD, Physics Lab, presets,
headless tests.

## 0.2 — mobile
- Touch controls: virtual joystick (move) + independent balance pad + jump button.
- iOS / Android export presets, on-device performance pass (target 60 fps on
  mid-range phones), safe-area UI.
- Camera: touch orbit, auto-framing during bounce.

## 0.3 — athlete model
- Two-body leg model (COM + feet, actuated spring) for richer bounce/landing.
- Fore-aft balance; turning around on the line.
- First Blender character + animation set.

## 0.4 — tricks & progression
- Trick controller (drop knee, butt bounce, chest bounce, 180/360, flips).
- Scoring, combos, arcade progression, unlockable lines/locations.

## Open questions
- Target devices / minimum spec.
- Desired difficulty curve: how much balance assist by default.
